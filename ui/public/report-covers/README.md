# Обложки объектов для печатной формы отчёта

> ⚠️ Источник обложек — **Supabase Storage**, бакет `report-covers`
> (публичный, только PNG). Эта папка в репозитории больше **не**
> используется для хранения картинок — оставлена только под эту памятку.

## Куда загружать

Папка (бакет) в Supabase Studio — открыть в браузере и перетащить файлы:

**http://192.168.1.113:54323/project/default/storage/files/buckets/report-covers**

## Именование файлов

Имя файла = **номер объекта** = префикс кода объекта до первого
подчёркивания (тот же номер, что в заголовке объекта), расширение `.png`.
Имя стабильно привязано к объекту и не зависит от состава/порядка отчёта.

## Что на картинке

Только **графика** (карта / рендер / визуализация). Заголовок объекта
(**Название + площадь участка**) система дорисовывает **над** картинкой
автоматически — дублировать его на PNG не нужно.

## Рекомендации по формату

- Ориентация — желательно **альбомная** (шире, чем выше): так картинка
  вместе с заголовком уместится на один лист A4.
- Масштабируется по ширине листа, высота ≤ ~235 мм, пропорции сохраняются.
- Разрешение под печать — ширина от ~1600 px. Только PNG, до 15 МБ.

## Если файла нет

Если PNG для объекта не загружен — на титульном листе показывается
авто-схема (SVG общий план с красным выделением участка). Обложки можно
добавлять по одной, постепенно.
